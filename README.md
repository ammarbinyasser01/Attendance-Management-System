# AI-Based Attendance Management System

An AI-powered Attendance Management System built with **Python**, **CustomTkinter**, **SQLite**, **OpenCV**, and **DeepFace**. The system provides separate dashboards for students and teachers with secure face verification before attendance access.

## Features

- Student and Teacher Login
- Face Registration
- Face Verification before Attendance Access
- Student Attendance Dashboard
- Teacher Attendance Management
- Attendance Graphs and Statistics
- Course Management
- User Feedback System
- SQLite Database Integration
- Modern CustomTkinter Interface

## Technologies Used

- Python
- CustomTkinter
- SQLite
- OpenCV
- DeepFace
- TensorFlow
- Pillow
- Matplotlib

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Attendance-Management-System.git
cd Attendance-Management-System
```

2. Install the required packages

```bash
pip install -r requirements.txt
```

3. Run the project

```bash
python main.py
```
